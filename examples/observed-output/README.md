# Observed ACE output

The three TXT files here were generated by ACE for the bundled single-source demonstration inputs at 50 RFU with GlobalFiler_3500 and ABI-LIZ-600-60-TO-460. They are tab-delimited text files despite the TXT extension.

These tables contain software calls, fragment sizes and RFU heights. They are not reference genotypes and do not by themselves establish accuracy. The separate reference values are in [known-genotypes.tsv](../provedit/known-genotypes.tsv).

The internal ladder TXT and local project state files are omitted. Full working projects and test logs are kept outside the upload repository.
